# Christmas Piano

A physical eight-key piano that plays sounds and changes the color of the Govee lights on a house.

## Language

**Key**:
One of the physical buttons a player presses on the piano.
_Avoid_: Button (except when talking about wiring), bell

**Chord**:
Two or more Keys pressed at the same moment.
_Avoid_: Combo, multi-press

**Note**:
The sound a single Key plays.
_Avoid_: Tone, sample

**Sound Pack**:
A named set of Notes, one for each Key.
_Avoid_: Theme, instrument

**Resting Look**:
The appearance the lights return to when nobody has played for a while.
_Avoid_: Idle state, default scene
